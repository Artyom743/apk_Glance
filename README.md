# Glance  

## Описание  
Glance — это Android-приложение, которое показывает время прибытия автобусов прямо на рабочем столе через виджет. Никаких лишних открытий приложения — просто включил телефон и сразу увидел нужную информацию.  

## Минимальная поддерживаемая версия Android  
- **Минимальная версия**: Android 8.0  
- **Рекомендуемая**: Android 9.0+

## Технические требования  
Запускать без VPN  

## Скачивание, запуск и интерфейс  
- Скачайте APK файл, приложенный в репозитории, на телефон
- Запустите его и дождитесь скачивания приложения(10 - 20 секунд)  
- Вытащите виджет на рабочий стол (потом размер виджета можно будет подогнать под желаемые параметры) и нажмите кнопку "Настройка"  
- Выберете интересующие вас оостановки, а также количество отображаемых автобусов, после чего нажмите на кнопку "Подтвердить"  
- Для подписки на маршрут, требуется нажать кнопку с галочкой на плашке с информацией о нём. Для отписки повторно нажмите кнопку  
- Меняйте остановки и подписывайтесь на маршруты, сколько это будет необходимо, после чего нажмите на кнопку "Завершить настройку"
- Перед вами появится окно с выбранными вами маршрутами, которые будут обновляться каждую минуту (последнее время обновления можно посмотреть на плашке сверху)  
- Так же вы сами можете гарантированно обновить свои маршруты, нажав на значок перезагрузки (обновление произойдёт в течение минуты)   
- Если вам нужно перенастроить подписки на маршруты, то вы можете нажать на кнопку рядом с перезагрузкой для повторного переключения в режим настройки
